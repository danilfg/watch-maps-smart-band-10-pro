Выбери маршрут.
Подготовь для браслета.

Москва и другие города. Пешком или на велосипеде. Яндекс Карты — для привычного поиска маршрутов, OpenStreetMap — для независимого расчёта.

1. Построить маршрут

Нажми на карте первую точку, затем вторую. Можно использовать GPS телефона.

Сервер маршрутизации

По умолчанию используется публичный демосервер Valhalla без гарантий доступности. Для постоянного использования разверни собственный экземпляр.

2. Импорт из Яндекс Карт

Построй маршрут в Яндексе, нажми «Поделиться» и вставь полную ссылку сюда. Существующий вход в Яндекс остаётся только у Яндекса.

Это импорт начальной и конечной точки, а не точной линии из Яндекса. Маршрут на нашем сайте строится заново по OpenStreetMap. Короткие ссылки пока не поддерживаются.

3. Экспорт для браслета

Можно загрузить готовый GPX или экспортировать построенный маршрут для будущего RPK и Bluetooth-моста.
